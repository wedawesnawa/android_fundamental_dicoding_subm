## About 
This project is part of my learning journey in Kotlin and Android application development, focusing on fundamental concepts and components used to build modern Android applications.

The project covers several Android development topics, including Fragment, Navigation, Android Architecture Components, API integration, background tasks and scheduling, and local data persistence.
